# D1Trailers Front-End

This repository contains the front-end of the D1Trailers website, built with **Next.js 13**, **React**, **Tailwind CSS**, and **Google Fonts**. It is designed to be minimal, maintainable, and ready for integration with back-end services (Stripe, Google Sheets, etc.).

## Stack

- **Next.js (App Router)**: For routing and server-side optimizations.
- **React.js**: Front-end component architecture.
- **Tailwind CSS**: Utility-first styling.
- **Google Fonts**: Inter (default) and Syne (for special headings) via `next/font/google`.
- **Heroicons**: For header menu icons.

## Fonts

- **Inter**: Default font for body and regular text.
- **Syne**: Optional font for headings or special callouts via the `.font-syne` class.

# Install dependencies

```bash
npm install
```

or

```bash
yarn
```

# Run development server

```bash
npm run dev
```

or

```bash
yarn dev
```

Open http://localhost:3000 in your browse
